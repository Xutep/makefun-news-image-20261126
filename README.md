A program that draws one newspaper-style image summing up the world's news of Thursday 26 November 2026: Pakistan's first astronaut flies to China's space station, Russia's own figures put its Ukraine war dead near 500,000, police free 20 hostages after a 17-hour supermarket siege in Colombia, BepiColombo reaches Mercury after an eight-year voyage, a Cairo tanker fire kills at least 30, and Gukesh draws Game 2 of the World Chess Championship in 20 moves. Pure Python standard library — the rasteriser, the 5x7 bitmap font and the PNG encoder are all written in `main.py`, so it runs with no network and no installed packages. Two runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024).
